How it works

Three small pieces, each replaceable.

1 · fsharp-wasm
The compiler. F# source → typed AST → WasmGC, with exact .NET semantics for integers, floats, strings, printf, generics and structural equality — verified by differential tests against .NET on every commit.
2 · Browser.*
Elmish, HTML and Canvas written in F# and compiled by the same compiler. The view is a pure function; the runtime serialises it, the host morphs the DOM.
3 · browser.js
About 100 lines. WasmGC strings are opaque to JavaScript, so text crosses the boundary as UTF-16 code units through two integer imports. No bridge generator, no shared memory.
type Msg = Increment | Decrement | Reset

let update msg model =
    match msg with
    | Increment -> model + 1
    | Decrement -> model - 1
    | Reset     -> 0

let view model =
    article [] [
        h1 [] [ text "Hello from F# on WasmGC" ]
        p  [] [ text ("Count: " + string model) ]
        button [ onClick Increment ] [ text "+" ]
    ]

let main () = run (simple 0 update view Reset)
